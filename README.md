# AURELIA — премиальный каталог автомобилей

Редизайн car-catalog с той же структурой вкладок (Главная / Каталог / Регионы / Бренды),
но в премиальном визуальном стиле: тёмный «шоурум»-фон, анимированный автомобильный
силуэт на главном экране, палитра на основе Pantone Color of the Year 2026 (Cloud Dancer)
в сочетании с бронзовым металликом и хромом.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

## Что внутри

- **Vite + React + TypeScript + Tailwind CSS v4**
- `react-router-dom` (HashRouter — подходит для GitHub Pages)
- Моковые данные (`src/data/mock.ts`) — 6 премиальных вымышленных брендов, 12 моделей,
  8 регионов. Замените на реальный источник (Supabase/API) при интеграции.

## Дизайн-система

- **Цвет**: obsidian `#0A0A0C` (фон) · cloud `#F2F0EA` (текст, эхо Pantone Cloud Dancer 2026) ·
  bronze `#C08A3E` / bronze-glow `#F0C989` (единственный смысловой акцент — свет фар, цена, hover) ·
  chrome `#DADCE0` / `#8B8E96` (линии кузова, нейтральные детали)
- **Шрифты**: Unbounded (заголовки) · Manrope (текст) · Space Mono (цифры/характеристики)
- **Сигнатурный элемент**: самопрорисовывающийся SVG-силуэт автомобиля с пульсирующей фарой
  и лучом света, «проходящим» по сцене — единственная яркая анимация, вокруг — сдержанная сетка
