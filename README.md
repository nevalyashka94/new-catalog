# AURELIA — премиальный каталог автомобилей

## Быстрый старт

```bash
npm install
npm run dev
```

## Подключение реальных данных (Supabase)

Сайт готов к работе с реальной базой `car-catalog` (таблицы `brands`, `cars`, `dealers`,
`car_dealers`). Пока переменные окружения не заданы — сайт работает на демо-данных
(`src/data/mock.ts`), это видно по жёлтой плашке в модалке дилеров.

1. Скопируйте `.env.example` → `.env`, впишите `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`
   (Supabase → Settings → API → Project URL / anon public).
2. Для продакшена (GitHub Pages) значения задаются не в `.env` (он не коммитится), а через
   **Settings → Secrets and variables → Actions** в репозитории:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   - `VITE_ADMIN_PASSWORD` (пароль для кнопки Admin в шапке сайта)

   Workflow (`.github/workflows/deploy.yml`) уже подставляет их в сборку.
3. Для загрузки фото из админки нужен bucket `cars` в Supabase Storage с публичным чтением —
   он уже используется исходным car-catalog, отдельно создавать не нужно.

## Что нового в этой версии

- **Тема + фары**: переключатель ☾/☀ в шапке. В тёмной теме у машины на главном экране
  горит и пульсирует фара с бронзовым свечением, в светлой — гаснет.
- **Карточка авто**: фото (или стилизованная заглушка, пока фото не загружено) + кнопка
  «Подробнее» → модалка с дилерами этой модели и быстрыми фильтрами по городу
  (Москва / Питер / Екатеринбург / Челябинск).
- **Каталог**: цена от–до, кузов, бренд, поиск по модели/марке + быстрые ценовые категории
  (до 2 млн / 3–4 млн / 5–6 млн / 7 млн+).
- **Админка**: кнопка «Admin» в шапке (пароль из `VITE_ADMIN_PASSWORD`), на каждой карточке
  появляется ✎ — редактирование бренда, кузова, цены и фото. Это лёгкая клиентская защита UI,
  а не полноценная аутентификация — для боевого использования стоит перейти на Supabase Auth
  + RLS, как уже частично сделано в исходном car-catalog (`ProtectedRoute`/`Login`).
- **Регионы**: дилеры сгруппированы по городу (поле `dealer_group` в таблице `dealers`,
  например `"1 Москва"`, автоматически очищается до `"Москва"`).

## Дизайн-система

- **Цвет**: obsidian `#0A0A0C` / cloud `#F2F0EA` (тёмная тема) — палитра инвертируется для
  светлой темы через `[data-theme="light"]` в `index.css`, все компоненты используют
  CSS-переменные, поэтому переключение темы не требует правок в JSX.
- **Шрифты**: Unbounded (заголовки) · Manrope (текст) · Space Mono (цифры/характеристики)
